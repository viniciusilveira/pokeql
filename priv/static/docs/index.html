Pokeql GraphQL API

A GraphQL API for Generation 1 Pokémon data.

Data is sourced from PokeAPI, persisted to PostgreSQL, and served from an in-memory ETS cache.

Endpoint: http://localhost:4000/api/graphql

Interactive explorer: http://localhost:4000/graphiql (development only)

All queries are read-only. No authentication required for local use.

API Endpoints
http://localhost:4000

0.1.0

Queries

abilities

Description

List abilities

Response

Returns [Ability!]!

Arguments
Name Description
limit - Int Maximum number of results to return. Default: 100.
offset - Int Number of results to skip for pagination. Default: 0.

Example

Query
query abilities(
  $limit: Int,
  $offset: Int
) {
  abilities(
    limit: $limit,
    offset: $offset
  ) {
    id
    name
    generationName
    isMainSeries
    shortEffect
  }
}

        "name": "xyz789",

        "isMainSeries": false,
        "shortEffect": "xyz789"
      }
    ]
  }
}

  "shortEffect": "abc123"

Types

ID

Description

The ID scalar type represents a unique identifier, often used to refetch an object or as key for a cache. The ID type appears in a JSON response as a String; however, it is not intended to be human-readable. When expected as an input type, any string (such as "4") or integer (such as 4) input value will be accepted as an ID.

Example
4
Types

Int

Description

The Int scalar type represents non-fractional signed whole numeric values. Int can represent values between -(2^31) and 2^31 - 1.

Example
987

Move

Description

A battle move that a Pokemon can learn and use.

Fields
Field Name Description
id - ID Unique move identifier.
name - String Move name, e.g. tackle.
generationName - String Generation in which this move was introduced.
power - Int Base power of the move (null for non-damaging moves).

accuracy - Int Percentage chance the move will hit (null for moves that bypass accuracy checks).
priority - Int Determines order within a turn (higher acts first).
typeName - String Elemental type of the move, e.g. normal.
damageClassName - String Whether the move is physical, special, or a status move.
shortEffect - String Brief description of what the move does.

  "pp": 123,
  "accuracy": 123,
  "priority": 123,

  "shortEffect": "abc123"

Types

Pokemon

Description

A Pokemon — a catchable creature with stats, types, abilities, and learnable moves.

Fields
Field Name Description
id - ID National Pokedex number.
name - String Pokemon name, e.g. pikachu.
height - Int Height in decimetres.
weight - Int Weight in hectograms.
order - Int Sort order for display purposes (species-level ordering).
isDefault - Boolean Whether this is the default form of the species.
baseExperience - Int Base experience points gained by the opponent when this Pokemon is defeated.
totalBaseStats - Int Sum of all base stats — a quick power indicator.
typeNames - [String] List of elemental type names this Pokemon has, e.g. ["grass", "poison"].
abilityNames - [String] List of ability names this Pokemon can have.
species - Species Species classification and biological metadata.
types - [PokemonType] Elemental types with full type details.
abilities - [Ability] Full ability objects including descriptions.
stats - [PokemonStat] Base stats and EV yields for each stat.
sprites - Sprite Sprite image URLs for this Pokemon.
moves - [PokemonMoveDetail] Moves this Pokemon can learn. Filter by versionGroup to get learn method and level details.
Arguments
versionGroup - String

Filter moves to a specific version group, e.g. red-blue. Omit to return all learnable moves without version detail.
Example
{
  "id": 4,
  "name": "abc123",
  "height": 123,
  "weight": 123,
  "order": 987,
  "isDefault": false,
  "baseExperience": 123,
  "totalBaseStats": 987,
  "typeNames": ["abc123"],
  "abilityNames": ["xyz789"],
  "species": Species,
  "types": [PokemonType],
  "abilities": [Ability],
  "stats": [PokemonStat],
  "sprites": Sprite,
  "moves": [PokemonMoveDetail]
}

PokemonMoveDetail

Description

Details about how and when a Pokemon learns a specific move in a given version group.

Fields
Field Name Description
levelLearnedAt - Int Level at which the move is learned (0 for non level-up methods).
learnMethod - String How the move is learned, e.g. level-up, machine, egg.
move - Move The move being learned.
versionGroup - VersionGroup The game version group this learning detail applies to.
Example
{
  "levelLearnedAt": 123,
  "learnMethod": "abc123",
  "move": Move,
  "versionGroup": VersionGroup
}
